# GitHub repository "About" text

**Description:**
Native macOS audio mixer, recording studio and DJ app: per-application volume, 10-band EQ, compressor, reverb/delay, master
limiter, multitrack 24-bit WAV recording, 2/4-deck DJ with BPM sync. Swift/SwiftUI/Core Audio. macOS 12 Monterey and later.
No account, no cloud.

**Topics:** `macos` `swift` `swiftui` `core-audio` `audio` `mixer` `dj` `recording` `equalizer` `audio-driver`
`audioserverplugin` `per-app-volume` `wav` `bpm-detection`
